Features

HearthTone 的每一個功能，都服從同一條標準——它是讓你更靠近音樂，還是更遠。以下是它做到的四件事。

01 / Cloud跨平台雲端同步
你的曲庫，如影隨形

雲端曲庫，隨身同步。

一鍵接入主流音樂平台帳號，紅心歌單與收藏瞬間同步到本地。也支援直接播放網盤中的音檔——你的曲庫不再被單一平台綁定。

  • 接入主流音樂平台帳號
  • 紅心歌單與雲端收藏同步
  • 支援網盤音檔播放
  • 離線時本地曲庫照常可用
02 / Sound純粹聆聽
音質全檔免費

把音質還給耳朵。

沒有廣告、沒有直播、沒有雜訊。Hi-Res 全檔位免費開放，配上三段均衡器，聲音的細節由你親手校準。

  • Hi-Res 音質全檔免費
  • FLAC · 24bit / 96kHz
  • 三段均衡器（120Hz / 1kHz / 4kHz）
  • 零廣告、零直播、零打擾
03 / Interface介面與歌詞
看得見的音樂

介面如流動的光。

多套精選面板可一鍵切換，WebAudio 即時頻譜讓節奏被看見，沉浸式歌詞把每個字放在它該在的位置。

  • 多套主題面板一鍵切換
  • WebAudio 即時頻譜
  • 沉浸式滾動歌詞
  • 系統托盤常駐，一鍵喚回
04 / Local本機優先
One'sAI · 全在本地

一切都留在你的電腦。

One'sAI 歌曲解讀優先使用你本機的推理模型生成，未安裝也能離線降級——整個過程，資料不出你的裝置。

  • One'sAI 本地歌曲解讀
  • 優先本機推理模型（Ollama）
  • 未安裝自動離線降級
  • 無遙測、無行為上傳
